# 작업 기록 - 노트 JSON 응답 복구

- 일시: 2026-11-24 11:33 (Asia/Seoul)
- 작성자: Codex
- 작업 유형: 버그 수정

## 변경 범위

- Gemini, OpenRouter, Ollama의 노트 생성에서 깨진 JSON은 한 번 복구하고, 빈 응답이면 해당 요청을 한 번 다시 보낸다.
- 전사 조각 응답을 복구하지 못하면 그 조각의 원문을 병합에 사용한다. 노트 초안 응답을 복구하지 못하면 `NOTE_QUALITY_FAILED`로 처리해 기존 노트를 보존한다.

## 검증

- 모의 Gemini 응답으로 빈 응답 재시도, 잘린 JSON 복구, 원문 조각 사용, 초안 복구 실패를 확인했다. 관련 테스트 73개가 통과했다.
- 실서비스 호출을 제외한 검증은 460개 통과, 선택적 대형 STT 테스트 1개 건너뜀이었다. Ollama 클라우드 통합 테스트 3개는 크레딧 부족 응답(HTTP 402)으로 실패했다.
