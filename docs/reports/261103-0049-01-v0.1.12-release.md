## 리스크/이슈

- 이 커밋 시점에는 `0.1.12` 로컬 앱과 GitHub Actions 플랫폼 빌드가 아직 완료되지 않았다.
- GitHub Release 게시와 배포 파일 생성 완료는 별도 상태다. 빌드 파일은 Actions 성공 후 첨부된다.
- macOS 앱은 ad-hoc 서명이며 Applications 설치는 이번 빌드 명령에 포함하지 않는다.
