# 작업 기록 - LLM 입력 중복 제거 / v0.1.16

- 일시: 2026-11-16 09:25 (Asia/Seoul)
- 작성자: Codex
- 작업 유형: 버그 수정 / 핫픽스 준비

## 요약

- 정제 chunk와 관련된 ASR segment·인접 문맥·재전사 후보만 전달한다.
- Gemini PDF는 작업당 한 번 참고문으로 추출하고 이후 생성·병합·보정에서 재사용한다.
- 동일 입력의 미리보기는 저장 시 재생성하지 않는다. 최근 8개 세션만 메모리에 보관한다.
- Ollama 짧은 노트는 전체 JSON 한 번 생성으로 통일했다.
- 콘텐츠 없는 요청별 토큰 사용량 로그를 추가했다.
- 버전을 0.1.16으로 갱신하고 릴리즈 workflow에 macOS DMG 첨부와 체크섬 포함을 추가했다.

## 검증

- 관련 테스트 59개 통과(LLM adapter, 입력 예산, PDF context, 서비스, GUI 대기열, 버전).
- 합성 전사문 53,649자 / 7 chunk: 총 입력 문자 352,633 → 138,145(60.8% 감소).
- 위 수치는 문자 수이며 실제 API 청구 토큰 절감률이 아니다.
- 전체 자동 테스트: 421 passed, 1 skipped (38.10s). CLI 도움말 및 git diff --check 통과.
- 검증 로그: build/hotfix-0.1.16/checks.log, 종료 상태 checks.exit = 0.
- tests/test_ollama_llm.py, tests/test_ollama_integration.py는 실제 서비스/사용자 workspace에
  의존하는 수동 통합 테스트이므로 제외한다. 유료 API와 실제 장치 검증은 실행하지 않았다.

## 배포 상태 및 제한

- GitHub 세 OS 빌드 성공 후 v0.1.16 핫픽스를 게시한다. CI 성공을 확인하기 전에는
  릴리즈 완료로 간주하지 않는다.
- 사용자 요청으로 로컬 macOS 빌드·설치는 보류했다. 실행 중인 앱은 변경하지 않았다.
- PDF 참고문은 최대 8,000자로 압축하므로 원본의 세부 정보가 생략될 수 있다.
- 코드 서명·공증은 기존 정책을 유지한다.
