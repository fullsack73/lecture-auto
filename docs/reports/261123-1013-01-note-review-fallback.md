## 변경 범위

- 내용 검토 후 보완과 재검토를 유지한다. 지적이 남아도 필수 내용이 갖춰진 노트를 반환하고 해당 섹션 이름을 로그에 기록한다.
- 보완본의 필수 내용이 빠지면 원래 초안을 검증해 사용한다. 어느 쪽도 필수 내용을 충족하지 못하면 기존 저장본을 보존한다.
- 예제 목록은 간단한 색인으로 쓸 수 있고 풀이는 본문에 둔다. 생성 실패 안내는 모델의 노트 생성을 설명한다.

## 검증

- 모의 응답으로 재검토 지적이 남는 경우와 필수 내용이 누락된 경우를 검증했다.
