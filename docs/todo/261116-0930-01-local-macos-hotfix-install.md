## 목표

LLM 입력 중복 수정이 포함된 앱을 이 Mac에서 재빌드하고 안전하게 설치한다.

## 요구사항

- 사용자의 "로컬 빌드는 나중에" 지시에 따라 현재는 실행하지 않는다.
- 앱이 종료되었는지 확인하고 녹음·작업을 강제로 종료하지 않는다.
- ARM64 Python 3.11 환경 `.venv311`과 기존 빌드·안전 설치 스크립트를 사용한다.
- 패키징 경량 import, 서명, 설치 smoke test가 통과한 뒤 설치본을 교체한다.
- 장시간 명령은 nohup, 절대 경로 로그·PID·종료 상태를 기록하고 2분 인계 규칙을 따른다.
